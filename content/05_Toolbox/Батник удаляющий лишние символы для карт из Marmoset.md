### Как создать и запустить скрипт

Чтобы быстро убрать нижнее подчеркивание `_` в начале имен всех файлов в папке, выполните эти шаги:

1. **Создайте файл:** Нажмите правой кнопкой мыши в папке с файлами -> **Создать** -> **Текстовый документ**.
2. **Назовите его:** Переименуйте файл в `rename_files.bat` (важно, чтобы расширение было **.bat**, а не `.txt`).
3. **Вставьте код:** Нажмите на файл правой кнопкой -> **Изменить** и вставьте этот текст:
```
@echo off
cd /d "%~dp0"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Get-ChildItem -Filter '_*' | Rename-Item -NewName {$_.Name -replace '^_', ''}"
echo Готово! Нажмите любую клавишу...
pause
```

4. **Запустите:** Просто кликните по файлу **дважды**. Скрипт сам найдет все файлы с `_` в этой папке и переименует их.

---

### Важные моменты:
- **Безопасность:** Скрипт работает только в той папке, в которую вы его положили.
- **Дубликаты:** Если после удаления `_` получится имя, которое уже есть в папке (например, были файлы `_test.txt` и `test.txt`), PowerShell выдаст ошибку для этого конкретного файла, но остальные переименует.
